# tg-max-vk

Мост между Telegram и MAX: посты, опубликованные в Telegram-канале,
автоматически дублируются в MAX. Ответы из MAX возвращаются в Telegram.

## Что умеет

- 📤 Пересылка текстовых сообщений Telegram → MAX
- 📥 Ответы из MAX → Telegram (с сохранением reply-связи)
- 🔒 Защита от эхо-циклов
- ⏱ Rate limiting (MAX: 2 msg/sec, Telegram: 1 msg/sec в чат)
- 🛡 Авторизация с поддержкой 2FA
- 💾 Сессия и маппинги в SQLite

## Быстрый старт

### 1. Получите токены

**Telegram:**
1. Зайдите на https://my.telegram.org
2. API development tools → создайте приложение
3. Скопируйте `api_id` и `api_hash`

**MAX:**
1. Откройте диалог с `@MasterBot` в MAX
2. Создайте бота, получите токен
3. Добавьте бота администратором в целевой канал
